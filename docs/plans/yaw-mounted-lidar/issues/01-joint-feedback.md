# #6 — 贯通带测量时间的大 Yaw 关节角与转速反馈

**GitHub:** https://github.com/Wanqiq7/Pldx_ws/issues/6

**Label:** ready-for-agent

## What to build

让导航侧能够取得同一测量时刻的大 Yaw 关节角和关节角速度，从电机反馈、下位机通信到 ROS 接收完整贯通，并能按 LIO 的时间轴对齐。关节角定义为大 Yaw 转动端相对实体底盘的角度，关节角速度定义为该角度的变化率；它们都不是雷达对世界的航向或转速。

当前 MID360 固定在大 Yaw 转动端，参考工程的雷达固定在底盘。第一阶段只处理大 Yaw，其他会改变雷达安装的机构在验证时固定。本工单只提供后续底盘状态恢复所需的反馈，不切换现有导航运行链。

## Acceptance criteria

- [ ] ROS 可观察到关节角 rad、关节角速度 rad/s、关节/参考系标识和测量时间；冻结这一消息契约，使后续工单无需重新猜测字段语义。
- [ ] 角度和转速来自同一电机采样；若原始来源异步，明确每个字段的采样时间和对齐规则，不把一次聚合发布误当作同期采样。
- [ ] 优先复用 LibXR 现有源时间戳能力，贯通电机采样时间；建立并说明 MCU 时间到 ROS/LIO 时间的映射，不直接将 MCU 微秒计数写成 ROS 时间，也不用接收 now() 冒充采样时刻。
- [ ] 核对电机解码、反向配置、传动比和关节零位处理；将软件可确认的单位与方向写入反馈契约，实机零位和安装标定由工单 06 验证。
- [ ] 用可重复的电机反馈注入/通信回放，验证已知角度和转速能穿过下位机发送、上位机解包与 ROS 发布；覆盖时间偏移、传输延迟、时间计数边界及关节角跨越 ±π，保留观测结果。
- [ ] 保留现有离线信息与其他通信功能，不因新增反馈改变已有消息的解释；遵守用户要求，沿用现有超时处理，不新增停止门控或降级状态机。

## Blocked by

None — can start immediately.
