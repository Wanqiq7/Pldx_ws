# #9 — 使用实体底盘朝向转换下位机平移指令

**GitHub:** https://github.com/Wanqiq7/Pldx_ws/issues/9

**Label:** ready-for-agent

## What to build

让 ROS 通信桥使用恢复后的实体底盘朝向及角速度，将现有世界坐标系平移指令转换为下位机要求的 chassis-frame 速度。大 Yaw 独立扫转时，给定的世界平移方向保持正确，不再随雷达朝向变化而错误旋转。

下位机已将接收的 XY 定义为底盘坐标系速度，并直接交给底盘控制；本工单保留这一线缆协议语义，修正上位机方向转换的状态来源。提供独立通信验证配置，正式切换在工单 05 完成。

## Acceptance criteria

- [ ] 朝向和角速度输入使用 `/chassis/odom`，不再以原始 LIO 转动端 yaw 和 angular.z 代表实体底盘。
- [ ] 指令 XY 与用于转换的底盘朝向属于同一世界参考系；当前链路使用 `camera_init`，不能只改订阅话题而混用 `map` 与 `camera_init`。
- [ ] 已有指令旋转延迟补偿使用底盘朝向/角速度和正确测量时间，保留现有命令与里程计超时语义。
- [ ] 下位机接收的 XY 仍为 chassis-frame，角速度仍表达原有底盘控制意图；不把关节角速度作为自旋指令相加，也不再次进行雷达杆臂补偿。
- [ ] 通过可重复的传输捕获或下位机接收测试验证实际出站数据，覆盖底盘静止大 Yaw 扫转、底盘转动、两者同时运动和固定世界方向指令；测试不驱动真实硬件。
- [ ] 行为模式与已有通信消息保持兼容，不新增停止门控或降级状态机。
