# #11 — 完成大 Yaw 台架标定与实体底盘四工况验收

**GitHub:** https://github.com/Wanqiq7/Pldx_ws/issues/11

**Label:** ready-for-human

## What to build

由实机操作人员在其他会改变雷达安装的机构固定时，使用已集成的记录和验收入口完成大 Yaw 零位、方向、转轴及雷达安装标定，验证实体底盘状态恢复和指令方向在真实硬件上成立。将实测结果形成可复核报告，明确哪些结论已通过实机验证。

当前 CAD 安装值仅作为初值，电机配置仍有待实机确认的占位信息；底盘 IMU 可以辅助核对相对转角，但未经零位对齐不能直接当作 LIO 世界航向真值。本工单涉及真实机构操作与运动，不能由离线合成测试替代。

## Acceptance criteria

- [ ] 记录最终使用的硬件配置、固定机构状态、关节零位、正方向、实际传动关系、转轴和 IMU 安装几何；区分 CAD 初值与实测标定值。
- [ ] 记录关节反馈到 LIO 时间轴的对齐误差/抖动，采用静止基线与可用测量真值确定并说明验收容差，不把通信接收时刻等同于采样时刻。
- [ ] 底盘静止大 Yaw 扫转时，恢复底盘参考点位置、朝向、线速度及角速度满足已记录的静止验收容差；雷达原始里程计仍显示真实关节运动。
- [ ] 关节锁定底盘旋转及两者同时运动时，保留实体底盘运动并正确分离关节转动，解析速度与修正后位姿差分在说明的噪声/采样容差内一致。
- [ ] 固定世界方向平移指令在大 Yaw 扫转及底盘转动时均保持预期方向，实机出站命令仍满足底盘坐标系约定。
- [ ] 保存记录数据、参数与四工况结果，验证关键 TF 唯一发布和虚拟导航朝向；确认既有隧道/小陀螺等策略未因状态来源改变而失效。
- [ ] 发现的偏差按测量证据回写标定或另建具体问题，不通过新增冗余保护逻辑代替修正。
