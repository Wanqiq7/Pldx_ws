# rmuc_2025 启动失败修复

对照上游：https://github.com/Walker152/nav-simulation/tree/b95b8fc27e570c708dd0c0ae64603a286d666c98

## 原因

本地 rmuc_2025 的 world 和模型 SDF 与上述上游版本一致，资产完整。失败日志为 `Unable to resolve uri[model://rmuc_2025]`，指向旧 `rmu_gazebo_simulator` 安装目录中的失效符号链接。该目录优先于当前包被检索，SDFormat 找到同名目录后无法读取 model.config，导致整个 world 加载失败。

两层环境均需修正：SDFormat 优先检查 SDF_PATH；ROS Jazzy ros_gz_sim 的 gz_sim.launch.py 从 os.environ 构造 additional_env，会覆盖仅设置在 launch context 的 GZ_SIM_RESOURCE_PATH。因此在生成启动描述时，优先放置当前包资源，同时将环境同步给进程和 launch context。保留其他包路径，无需删除其他包的安装目录。

## 本次全部修改

1. `sentry_simulation/launch/simulation.launch.py`：在既有 resource_paths 调用之后，同步进程环境、优先设置 SDF_PATH，并新增对应的 SetEnvironmentVariable。

```python
    resource_key, resource_value = resource_paths(package_share)
    # ros_gz_sim builds additional_env from os.environ, not the launch context.
    # Keep this package's models ahead of other workspace simulation packages.
    os.environ[resource_key] = resource_value
    # SDFormat checks SDF_PATH before Gazebo's resource lookup callback.
    sdf_path = os.pathsep.join([
        str(Path(package_share) / "resource/models"), os.environ.get("SDF_PATH", "")
    ])
    os.environ["SDF_PATH"] = sdf_path
    return LaunchDescription([
        SetEnvironmentVariable(resource_key, resource_value),
        SetEnvironmentVariable("SDF_PATH", sdf_path),
```

2. 新增 `sentry_simulation/scripts/check_world_resources.py`，完整代码如下：

```python
#!/usr/bin/env python3
"""Validate world/model resolution using the launcher's process environment."""
from pathlib import Path
import runpy
import subprocess

from ament_index_python.packages import get_package_share_directory
import yaml


def main():
    share = Path(get_package_share_directory("sentry_simulation"))
    launch = runpy.run_path(str(share / "launch/simulation.launch.py"))
    launch["generate_launch_description"]()
    worlds = yaml.safe_load((share / "config/worlds.yaml").read_text())
    for name, config in worlds.items():
        world = share / config["world"]
        assert world.is_file(), f"Missing world: {world}"
        subprocess.run(["gz", "sdf", "-k", str(world)], check=True)
        print(f"PASS: {name}", flush=True)


if __name__ == "__main__":
    main()
```
