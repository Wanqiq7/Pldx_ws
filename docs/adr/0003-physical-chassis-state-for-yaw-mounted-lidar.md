# 为大 Yaw 雷达恢复实体底盘状态

Status: accepted (design scope; implementation pending)

当前雷达固定在大 Yaw 转动端，参考 `navi_minco_bit` 的雷达固定在底盘，固定安装外参不能直接沿用。用户选择恢复实体底盘参考点的位置、朝向和速度，供 MINCO、MPC 与指令坐标转换一致使用，并保留导航虚拟参考系用于现有 Nav2；不选择把本次工作改为只控制 XY、独立重设 yaw 语义的方案。这将实体底盘运动与雷达随关节的运动分开，也避免只改变 TF 后直接读取 LIO 的控制代码仍使用雷达朝向。

第一阶段只适配大 Yaw 自由度，验证时固定其他会改变雷达安装的机构；用户允许同步完善上下位机的关节角、关节转速与测量时间反馈。

第二轮中，用户选择统一状态转换节点发布 `camera_init → base_link` 与底盘里程计，安装链为 `base_link → lidar_yaw_mount → body`，Point-LIO 保留原始里程计而关闭原始 TF 广播。控制速度使用解析恢复，修正后的位姿差分用于验证。与把动态外参散落在各消费者中的做法相比，这样可使规划器、MPC 与通信出口共用一种底盘状态语义，并避免重复杆臂补偿。

用户要求“不要增加冗余安全保护”；沿用现有超时处理，本次不新增停止门控或降级状态机。用户已确认完整设计与六张工单拆分，工单已发布；本轮只记录设计和工单，运行代码实施另行进行，后续提交和推送使用 develop。既有 ADR-0002 的隧道命令策略归属保持适用。源码证据、推导和验收范围见[设计讨论](../tf_dynamic_lidar_discussion.md)，执行依赖见[工单总览](../plans/yaw-mounted-lidar/README.md)。
