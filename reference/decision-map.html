五棵树按主循环顺序排列

  1. resource_tree.xml 处理资源请求。
  2. tactical_tree.xml 选择并记录模式，供其他节点读取。
  3. nav_tree.xml 是主树。搜 NavPriorityRoot 看导航分支优先级。recovery_tree.xml 被它 include，恢复动作当前直接出现在主树中。
  4. stance_tree.xml 选择车体姿态。
  5. gimbal_tree.xml 处理云台相关行为。

追一个行为的读码顺序

找到 XML 标签 → 查 registerNodes() → 读 tick() 或 action 回调 → 查黑板键的读写方

导航分支何时被打断

  • 外层 NavPriorityRoot 是 ReactiveFallback。每轮从第一个子分支开始，遇到 FAILURE 就往下，遇到 RUNNING 或 SUCCESS 就结束本轮筛选。
  • 内层普通 Sequence 在连续被 tick 时会从上轮返回 RUNNING 的子节点继续。收到 halt() 后，下一次进入从第一个子节点开始。
  • 导航动作收到 halt() 时，由 Nav2 客户端基类判断是否请求取消当前目标。
